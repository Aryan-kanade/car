Full 4-phase roadmap to take KMKIRAMYKI from polished demo to ship-ready storefront. White theme, Phosphor, existing contexts and audit standards carry through; each phase ends with build + browser verification.

## Phase 1 — Close the commerce loop
1. **`/checkout` flow** (`pages/CheckoutPage.jsx`, guarded — redirects to /cart when empty):
   - Step 1 Contact & shipping (email, name, address, city, state, PIN — inline validation)
   - Step 2 Payment (demo card/UPI form, clearly marked, nothing stored)
   - Step 3 Confirmation: generates `KMK-XXXXXX` order, persists to `localStorage`, clears cart
2. **`src/utils/orders.js`** — saveOrder / findOrder(number, email) with items, totals, timestamp
3. **`/order-lookup` actually works** — finds real demo orders, shows status card (Placed → Shipped by age) + items; graceful "not found" stays
4. **`aria-live` cart announcements** in Layout (polite region: "Added X to cart")

## Phase 2 — PDP conversion depth
5. **Interactive gallery** — thumbnail buttons swap the main placeholder (front / angle / in-use)
6. **Size variants** — 500 ml (base) / 1 L (×1.8) on shampoos/cleaners, kit = no variant; selector updates price + compare-at; cart key becomes `id:size`; line items show size
7. **Sticky add-to-cart bar** — IntersectionObserver on the buy box; compact name/price/qty/add floats in when scrolled past (mobile-first)
8. **Delivery strip** — "Ordered before 4 PM IST ships today" + dispatch info on PDP
9. **Reviews** (`components/ReviewSection.jsx` + hook): star-breakdown bars, review list, write-review form (name/stars/text, inline success), persisted per product in localStorage; seeds existing 5★(1) for the Complete Detail Kit

## Phase 3 — Merchandising, content & SEO
10. **Mega menu** (desktop lg+): category grid + featured product preview; mobile menu unchanged
11. **Lab Notes blog** — `/notes` index + `/notes/:slug` with 3 real guides (two-bucket wash, wheel decon, coating prep), `data/notes.js`, per-page meta
12. **Structured data** — JSON-LD `Product` (name, INR price, availability) on PDPs; `Article` on notes
13. **`public/sitemap.xml`** (all ~22 URLs) + **`public/robots.txt`**
14. **Home "The Routine" strip** — 4 steps (Pre-Wash → Wash → Decontaminate → Protect) linking categories

## Phase 4 — Ship-readiness
15. **a11y hardening** — focus trap for drawer/search/modal (`hooks/useFocusTrap.js`), skip-to-content link
16. **Idle route prefetch** — after load, warm the lazy chunks so navigation is instant
17. **PWA manifest** (`public/manifest.webmanifest`) with icon; theme color
18. **Tooling** — ESLint (flat config) + Prettier, `npm run lint` clean; **git init + staged commits** per phase
19. **Final sweep** — impeccable across all routes (incl. new ones), console-error check

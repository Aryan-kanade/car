Round 2 roadmap — **Conversion, Delight & Resilience**. Same standards: build + browser verification + commit per phase.

## Phase 1 — Theme system: dark mode returns (toggle, white default)

- Tailwind v4 `@custom-variant dark` + `.dark` class on `<html>`, driven by a `useTheme` hook (localStorage `kmkiramyki-theme`, falls back to system preference, white default)
- **Sun/Moon toggle in the Navbar** (44px target, aria-pressed); `theme-color` meta updates live
- Sweep `dark:` variants across all ~25 components/pages: surfaces (white↔zinc-950, zinc-50↔zinc-900), placeholders (zinc-200↔zinc-800), text ramp, borders, inverted CTAs/badges (zinc-900↔white), hero gradients, scrollbar + focus-ring colors
- Verified by screenshots in both themes (impeccable audits stay on the default light render)

## Phase 2 — Conversion boosters

- **Promo codes** (`utils/promos.js`): `WELCOME10` (10% off) and `FREESHIP`; input + applied-chip in cart & checkout summaries; discount line in totals; orders snapshot the discount; invalid-code error state
- **Cart cross-sells**: "Complete your routine" row of 3 products not already in the cart
- **Stock urgency**: `stock` counts in catalog; "Only N left" indicator on PDP (and cards when ≤ 5) with low-stock styling

## Phase 3 — Delight tools

- **Dilution Calculator** (`/calculator`): pick a concentrate, set water volume (slider + input) → ml of product + capful equivalents, with add-to-cart link; dilution data per product in catalog; linked from Lab Notes, footer, sitemap, and mega menu
- **Back-to-top** floating button after 800px scroll
- **FAQ live filter** input

## Phase 4 — Resilience & QA

- **ErrorBoundary** around routed content with on-brand fallback
- **Vitest unit tests** for the pure logic: variant pricing/rounding, order save/find/status, promo math, wishlist/cart state helpers — `npm test` script
- **README.md** (stack, scripts, structure, deploy notes) + **`vercel.json`** SPA rewrite config
- Final sweep: ESLint + Prettier clean, build, impeccable across all routes, dual-theme browser walkthrough, per-phase commits

# KMKIRAMYKI — Deep-Research Improvement Audit (Round 3)

## Current state (already strong)

23 routes · complete demo commerce loop (cart→checkout→orders→lookup) · variants · promos · reviews · wishlist · search · dark mode · code-splitting · 15 unit tests · lint/format clean · impeccable 0 findings on all routes · 9 clean git commits.

The research (Baymard, motion.dev, React/W3C docs — sources cited in chat) mapped against this codebase found the following gaps, organized by dimension with impact/effort:

## 1. Accessibility — 1 confirmed bug + hardening

- **BUG: amber-600 urgency text = 3.2:1 contrast (fails AA 4.5:1)** → switch to amber-700 (5.05:1) on PDP + cards, both themes
- Focus not returned to trigger button after drawer/search close
- Sticky-header focus obscuring (WCAG 2.4.11) — add scroll-margin to focused targets
- Search overlay: announce result count via aria-live
- Add `eslint-plugin-jsx-a11y` static gate (WCAG 2.2: our 44px targets exceed the 24px minimum — good)

## 2. Performance — bundle & fonts

- **framer-motion → `motion` package** + `LazyMotion`/`m` components (~4.6 kB vs 25+ kB feature set; framer-motion in maintenance mode)
- **Self-host fonts** via `@fontsource-variable/inter` + `space-grotesk` (variable, one woff2 each) — kills Google CDN round-trips; metric-override fallbacks to remove swap CLS
- React Compiler v1 (stable) for free auto-memoization
- `react-router-dom` → `react-router` import slimming; Phosphor `unplugin` SVG sprite (zero runtime icons)
- Targets: LCP <2.5s (stretch 2.0), INP <200ms, CLS <0.1

## 3. SEO — biggest structural gap

- CSR = empty HTML until JS. **React Router 7 `prerender`** (works with ssr:false) for marketing routes: emits per-route static HTML — the sanctioned middle ground (avoid react-snap, dead since 2019)
- **og:image** missing — generate a branded 1200×630 SVG→PNG
- More JSON-LD: `Organization`, `WebSite`, `BreadcrumbList` (Product/Article already exist)
- Real domain swap in sitemap.xml/robots.txt at deploy

## 4. Conversion/UX — research vs our gaps

Already have: sticky ATC, stock urgency, browse-first nav, free-ship estimator, guest checkout. Missing, ordered:

- **Express wallet row** (demo Apple Pay/UPI/Card) at top of checkout + PDP [common — top conversion lever]
- **Mobile bottom nav** (75% one-handed usage) [common]
- **PDP gallery zoom** (hover magnify) [common]
- Trust layer at buy box (guarantee/returns/secure icons) [common]
- Reviews: verified badge + photo slots [common]
- **Before/after sliders** per product [differentiator]
- **Bundle builder** — "build your kit, 3+ items = 10% off" [differentiator, AOV]
- Surface-compatibility quiz; sustainability specifics (refill program, biodegradable) [differentiator]
